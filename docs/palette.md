# Palette: Calibration

Laser-level amber on instrument black. The line colours come from the Okabe-Ito set, brightened for a dark backdrop, so they stay distinct under the common forms of colour blindness. The source of truth for the app is `Sources/ScreenAlign/Palette.swift`; the demo SVG and README badges use the same values.

| Token | Hex | Use |
|-------|-----|-----|
| ink | `#0E1116` | Overlay backdrop, demo background |
| panel | `#171B22` | Info panel |
| panel edge | `#2A303A` | Panel outline, device bezels in the demo (`#232933`) |
| text | `#E8EAED` | Panel text, cursor guide at 85% |
| muted text | `#8B93A1` | Secondary labels |
| amber | `#FFB020` | Line 1, the primary accent |
| sky | `#56B4E9` | Line 2, links and badges |
| mint | `#2BD9A0` | Line 3, the aligned state |
| orchid | `#E58FC4` | Line 4 |
| vermillion | `#FF6A3D` | Line 5 |
| lemon | `#F0E442` | Line 6 |
